# start_frontend.sh

## Descripción
El script `start_frontend.sh` inicia el frontend en segundo plano usando tmux.

## Funcionamiento
- Comprueba si existe sesión tmux
- Si no existe, la crea
- Ejecuta npm run dev

## Qué es tmux
`tmux` es un gestor de sesiones que permite:
- Ejecutar procesos en segundo plano
- Mantenerlos vivos aunque cierres sesión
- Volver a conectarte después

Es una terminal que nunca se cierra


## Código
```bash
#!/bin/bash

SESSION="frontend"
RUTA="/mnt/TFG_CRIMSA/01_PROYECTO/CODIGO/frontend"

tmux has-session -t $SESSION 2>/dev/null

if [ $? != 0 ]; then
   echo "Iniciando frontend..."
   tmux new-session -d -s $SESSION
   tmux send-keys -t $SESSION "cd $RUTA" C-m
   tmux send-keys -t $SESSION "npm run dev" C-m
else
   echo "Ya está en ejecución"
fi
```

## Explicación línea por línea

### Flujo completo
- Comprueba si exite sesion
- NO exite
  - Crea tmux
  - Entra en carpeta
  - Ejecuta frontend
- SI Existe
  - Notifica que ya esta encendido

---

### 1. Definición de variables
```bash
SESSION="frontend"
RUTA="/mnt/TFG_CRIMSA/01_PROYECTO/CODIGO/frontend"
```
- SESSION: nombre de la sesión tmux
- RUTA: carpeta donde está el frontend

---

### 2. Comprobación de sesión existente
```bash
tmux has-session -t $SESSION 2>/dev/null
```
- Comprueba si ya existe una sesión llamada frontend
- 2>/dev/null oculta errores (para no ensuciar la terminal)

---

### 3. Evaluación del resultado
```bash
if [ $? != 0 ]; then
```
- $? = código de salida del último comando
- 0 = éxito (la sesión existe)
- distinto de 0 = no existe
  
Aqui pregunta si el frontend esta encendido

---

### 4. Si NO está encendido
```bash
tmux new-session -d -s $SESSION
```
- Crea una sesión nueva
- -d = en segundo plano (detached)
- -s = nombre de la sesión
  


```bash
tmux send-keys -t $SESSION "cd $RUTA" C-m
```
- Entra en la carpeta del frontend
- C-m = simula ENTER
  


```bash
tmux send-keys -t $SESSION "npm run dev" C-m
```
- Arranca el servidor frontend
  
Esto es como si escribieras comandos dentro de otra terminal



```bash
echo "✅ Frontend encendido en segundo plano"
```
 Mensaje que te informa que ya se encendio

---
### 5. Si YA está encendido
```bash
echo "⚠️ El frontend ya está en ejecución"
```
Para evitar procesos duplicados
