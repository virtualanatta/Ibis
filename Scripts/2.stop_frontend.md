# stop_fronmtend

## Qué hace este script
Este script detiene el frontend que está ejecutándose en segundo plano dentro de una sesión `tmux`.

Sirve para:

- apagar el servidor cuando ya no lo necesitas,
- evitar dejar procesos abiertos,
- controlar mejor el ciclo de vida del frontend.


## ¿Por qué no basta con cerrar la terminal?
Porque el frontend se arrancó dentro de `tmux`, que mantiene el proceso vivo aunque cierres la sesión SSH.

Entonces, para apagarlo bien, no basta con salir de la terminal.
Hay que:

- entrar o apuntar a la sesión tmux
- detener el proceso
- cerrar la sesión.

Este script hace eso automáticamente.


## Explicación línea por línea

### Flujo completo del script

- Busca la sesión frontend
- Si existe:
  - envía Ctrl + C
  - espera 1 segundo
  - elimina la sesión
  - confirma el apagado
- Si no existe:
  - avisa de que no hay nada encendido

``` 
#!/bin/bash

SESSION="frontend"

# Comprobar si existe la sesión
tmux has-session -t $SESSION 2>/dev/null

if [ $? == 0 ]; then
    echo "🛑 Apagando frontend..."

    tmux send-keys -t $SESSION C-c
    sleep 1
    tmux kill-session -t $SESSION

    echo "✅ Frontend detenido"
else
    echo "⚠️ El frontend no está en ejecución"
fi
```

## 1. Variable de sesión
``` 
SESSION="frontend"
```
Aqui se define el nombre de la sesion `tmux` la que quieres detener

El script buscara esa sesion

## 2. Comprobación de existencia
``` 
tmux has-session -t $SESSION 2>/dev/null
```
Comprueba que existe una sesion llamada frontend
- `-t $SESSION` indica el nombre de la sesión objetivo
- `2>/dev/null` oculta errores si la sesión no existe

## 3. Comprobación del resultado
``` 
if [ $? == 0 ]; then
```
- `$?` guarda la salida del ultimo comando 
- 0 es que si existe sesion otro es error que estara apagada
- si la sesión existe → continuar con el apagado
- si no existe → mostrar aviso

## 4. Apagado del frontend
``` 
echo "🛑 Apagando frontend..."
```
Informa que empieza el apagado

## 5. Enviar Ctrl + C al proceso
```
tmux send-keys -t $SESSION C-c
```
Este comando envia lo equivalente a `Ctrl + C` dentro de la sesion `tmux`

Esto es para detener el proceso de forma limpia
- no de forma brusca
- permites un cierre correcto
- evitas archivos corruptos

Detiene el `npm run dev` que si inicio en el script de start

## 6. Espera breve
``` 
sleep 1
```
Espera antes de cerrar la sesion es una pausa de seguridad

## 7. Eliminar la sesión tmux
``` 
tmux kill-session -t $SESSION
```
Una vez el proceso se paro se usa este comando para eliminar la sesion `tmux`

- no queda una sesion vacia
- limias el entorno
- listo para el proximo start

## 8. Confirmación final
``` 
echo "✅ Frontend detenido"
```
Te informa que se ha detenido


## 9. Si la sesión no existe
``` 
else
   echo "⚠️ El frontend no está en ejecución"
fi
```
En caso de no enocntrar sesion `frontend` no hace nada
