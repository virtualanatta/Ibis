# limpiar_backups.sh

## Qué hace este script
Este script elimina backups antiguos para liberar espacio en el sistema.

Sirve para:
- evitar que el disco se llene,
- mantener solo copias recientes,
- automatizar la limpieza,
- mantener ordenado el sistema de backups.

## Por qué se usa
Si haces backups de forma frecuente, el almacenamiento se llena rápidamente.

Este script evita ese problema eliminando automáticamente los backups más antiguos.

## Explicación línea por línea

### Flujo completo del script

- Define la carpeta de backups
- Define el tiempo máximo (días)
- Busca archivos antiguos
- Los elimina

```bash
#!/bin/bash

RUTA_BACKUPS="/mnt/TFG_CRIMSA/04_BACKUPS"
DIAS=7

find $RUTA_BACKUPS -type f -name "*.tar.gz" -mtime +$DIAS -exec rm {} \;
```

## 1. Ruta de backups
```bash
RUTA_BACKUPS="/mnt/TFG_CRIMSA/04_BACKUPS"
```
Define dónde están guardados los backups.

## 2. Días límite
```bash
DIAS=7
```
Indica cuántos días se conservan los backups.

En este caso:
- se mantienen 7 días
- todo lo más antiguo se elimina

## 3. Búsqueda de archivos antiguos
```bash
find $RUTA_BACKUPS -type f -name "*.tar.gz" -mtime +$DIAS
```
Este comando busca:
- archivos (`-type f`)
- con nombre `.tar.gz`
- más antiguos que los días definidos

## 4. Eliminación
```bash
-exec rm {} \;
```
Elimina cada archivo encontrado.

⚠️ Importante:
Esto borra archivos permanentemente.

## Qué consigue este script
Mantiene el sistema limpio y evita que los backups llenen el disco.
