# generar_dashboard.sh

## Qué hace este script
Este script genera información que luego puede mostrarse en un dashboard (panel web).

Sirve para:
- visualizar el estado del sistema,
- mostrar datos de uso,
- tener una vista clara desde el frontend,
- facilitar la monitorización.

## Por qué se usa
Aunque puedes ver datos con comandos, no es práctico para usuarios.

Este script prepara los datos para que puedan mostrarse en una web o dashboard.

## Explicación línea por línea

### Flujo completo del script

- Obtiene datos del sistema
- Formatea la información
- Guarda los datos en un archivo

```bash
#!/bin/bash

OUTPUT="/mnt/TFG_CRIMSA/03_DASHBOARD/datos.txt"

FECHA=$(date "+%Y-%m-%d %H:%M:%S")
DISCO=$(df -h /mnt/TFG_CRIMSA | awk 'NR==2 {print $5}')
MEMORIA=$(free -h | awk '/Mem:/ {print $3 "/" $2}')

echo "Fecha: $FECHA" > $OUTPUT
echo "Uso disco: $DISCO" >> $OUTPUT
echo "Memoria: $MEMORIA" >> $OUTPUT
```

## 1. Archivo de salida
```bash
OUTPUT="/mnt/TFG_CRIMSA/03_DASHBOARD/datos.txt"
```
Define dónde se guardarán los datos.

Este archivo será leído por el frontend o dashboard.

## 2. Fecha
```bash
FECHA=$(date "+%Y-%m-%d %H:%M:%S")
```
Obtiene la fecha actual.

## 3. Uso de disco
```bash
DISCO=$(df -h /mnt/TFG_CRIMSA | awk 'NR==2 {print $5}')
```
Obtiene el porcentaje de uso del disco.

## 4. Uso de memoria
```bash
MEMORIA=$(free -h | awk '/Mem:/ {print $3 "/" $2}')
```
Obtiene la memoria usada y total.

## 5. Guardar datos
```bash
echo "Fecha: $FECHA" > $OUTPUT
echo "Uso disco: $DISCO" >> $OUTPUT
echo "Memoria: $MEMORIA" >> $OUTPUT
```
- `>` sobrescribe el archivo
- `>>` añade información

## Qué consigue este script
Genera datos estructurados que pueden ser consumidos por una interfaz web.
