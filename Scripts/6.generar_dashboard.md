# ejecutar_backup.sh

## Qué hace este script
Este script realiza una copia de seguridad (backup) de los datos del proyecto.

Sirve para:
- proteger la información,
- evitar pérdidas de datos,
- poder restaurar el sistema en caso de fallo,
- mantener copias históricas.

## Por qué se usa
En cualquier sistema es fundamental tener backups.

Si ocurre un problema como:
- fallo de disco,
- borrado accidental,
- error humano,

puedes recuperar los datos gracias a las copias de seguridad.

## Explicación línea por línea

### Flujo completo del script

- Define la ruta de origen
- Define la ruta de destino
- Genera nombre con fecha
- Comprime los datos
- Guarda el backup

```bash
#!/bin/bash

ORIGEN="/mnt/TFG_CRIMSA"
DESTINO="/mnt/TFG_CRIMSA/04_BACKUPS"

FECHA=$(date +%Y%m%d_%H%M%S)
ARCHIVO="backup_$FECHA.tar.gz"

tar -czf $DESTINO/$ARCHIVO $ORIGEN
```

## 1. Ruta de origen
```bash
ORIGEN="/mnt/TFG_CRIMSA"
```
Define qué carpeta se va a copiar.

Normalmente incluye:
- código,
- base de datos,
- archivos del sistema.

## 2. Ruta de destino
```bash
DESTINO="/mnt/TFG_CRIMSA/04_BACKUPS"
```
Define dónde se guardarán los backups.

Es recomendable tener una carpeta específica para esto.

## 3. Generar fecha
```bash
FECHA=$(date +%Y%m%d_%H%M%S)
```
Genera una marca de tiempo única.

Esto permite:
- no sobrescribir backups,
- identificar cuándo se hizo cada copia.

## 4. Nombre del archivo
```bash
ARCHIVO="backup_$FECHA.tar.gz"
```
Construye el nombre del backup.

Ejemplo:
backup_20260415_183000.tar.gz

## 5. Crear el backup
```bash
tar -czf $DESTINO/$ARCHIVO $ORIGEN
```
- `tar` empaqueta archivos
- `-c` crea el archivo
- `-z` comprime en gzip
- `-f` define el nombre

Resultado:
un archivo comprimido con todo el contenido.

## Qué consigue este script
Permite generar copias de seguridad completas del sistema de forma rápida y automatizada.

## Relación con otros scripts
- `ejecutar_backup.sh` → crea backup
- `limpiar_backups.sh` → elimina backups antiguos
- `check_sistema.sh` → monitoriza estado
