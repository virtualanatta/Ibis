# notificar_ssh.sh

## Qué hace este script
Este script envía una notificación (por ejemplo a Telegram) cada vez que alguien se conecta al servidor por SSH.

Sirve para:
- saber quién accede al servidor,
- mejorar la seguridad,
- tener control en tiempo real de accesos.

## Por qué se usa
Cuando alguien entra por SSH normalmente no te enteras.
Este script automatiza ese aviso y lo envía a Telegram.

## Explicación línea por línea

### Flujo completo del script

- Detecta conexión SSH
- Obtiene usuario e IP
- Construye mensaje
- Envía notificación

```bash
#!/bin/bash

USER=$(whoami)
IP=$(echo $SSH_CONNECTION | awk '{print $1}')
FECHA=$(date)

MENSAJE="Nuevo acceso SSH:
Usuario: $USER
IP: $IP
Fecha: $FECHA"

curl -s -X POST https://api.telegram.org/bot$TOKEN/sendMessage \
-d chat_id=$CHAT_ID \
-d text="$MENSAJE"
```

## 1. Obtener usuario
```bash
USER=$(whoami)
```
Obtiene el usuario que ha iniciado sesión

## 2. Obtener IP
```bash
IP=$(echo $SSH_CONNECTION | awk '{print $1}')
```
Extrae la IP del cliente SSH

## 3. Obtener fecha
```bash
FECHA=$(date)
```
Guarda la fecha actual

## 4. Crear mensaje
```bash
MENSAJE="Nuevo acceso SSH:
Usuario: $USER
IP: $IP
Fecha: $FECHA"
```
Se construye el mensaje con la información

## 5. Enviar a Telegram
```bash
curl -s -X POST https://api.telegram.org/bot$TOKEN/sendMessage \
-d chat_id=$CHAT_ID \
-d text="$MENSAJE"
```
Se usa curl para enviar el mensaje usando la API de Telegram
