# registrar_acceso.sh

## Qué hace este script
Este script registra cada acceso al servidor en un archivo de log.

Sirve para:
- guardar un historial de conexiones,
- saber quién ha entrado al sistema,
- dejar trazabilidad de los accesos,
- complementar la notificación en tiempo real.

## Por qué se usa
El script de notificación avisa en el momento, pero no guarda un histórico local.
Este script sí lo hace.

Gracias a esto puedes revisar después:
- qué usuario entró,
- desde qué IP,
- en qué fecha,
- y cuál era el estado del almacenamiento en ese momento.

## Explicación línea por línea

### Flujo completo del script

- Define la ruta del log
- Obtiene fecha y hora
- Detecta el usuario conectado
- Detecta la IP remota
- Comprueba el uso del DAS
- Guarda toda la información en una línea del log

```bash
#!/bin/bash

LOG_FILE="/mnt/TFG_CRIMSA/05_SISTEMA/LOGS/historial_conexiones.log"

AHORA=$(date "+%Y-%m-%d %H:%M:%S")
USUARIO=$(whoami)
IP_REMOTA=$(echo $SSH_CONNECTION | awk '{print $1}')
[ -z "$IP_REMOTA" ] && IP_REMOTA="Local"

ESPACIO=$(df -h /mnt/TFG_CRIMSA | awk 'NR==2 {print $5}')

printf "%-20s | %-10s | %-15s | DAS: %-5s [LOGIN]\n" \
"$AHORA" "$USUARIO" "$IP_REMOTA" "$ESPACIO" >> $LOG_FILE
```

## 1. Ruta del archivo de log
```bash
LOG_FILE="/mnt/TFG_CRIMSA/05_SISTEMA/LOGS/historial_conexiones.log"
```
Aquí se define el archivo donde se guardará el historial de accesos.

Ese archivo funcionará como registro permanente de conexiones.

## 2. Obtener fecha y hora
```bash
AHORA=$(date "+%Y-%m-%d %H:%M:%S")
```
Guarda la fecha y hora actual con un formato claro.

Esto sirve para saber exactamente cuándo ocurrió cada acceso.

## 3. Obtener el usuario
```bash
USUARIO=$(whoami)
```
Obtiene el nombre del usuario que ha iniciado sesión.

Así puedes identificar quién ha accedido al sistema.

## 4. Obtener la IP remota
```bash
IP_REMOTA=$(echo $SSH_CONNECTION | awk '{print $1}')
```
Extrae la IP remota desde la variable del sistema `SSH_CONNECTION`.

En una conexión SSH, esa variable contiene información sobre el origen y destino de la conexión.

Con `awk '{print $1}'` se toma el primer valor, que corresponde a la IP del cliente.

## 5. Detectar si el acceso es local
```bash
[ -z "$IP_REMOTA" ] && IP_REMOTA="Local"
```
Si la variable de IP está vacía, el script interpreta que no se trata de una conexión SSH remota.

En ese caso asigna el valor `Local`.

Eso evita dejar campos vacíos y diferencia accesos locales de accesos remotos.

## 6. Obtener el uso del almacenamiento
```bash
ESPACIO=$(df -h /mnt/TFG_CRIMSA | awk 'NR==2 {print $5}')
```
Este comando consulta el uso del almacenamiento montado en `/mnt/TFG_CRIMSA`.

- `df -h` muestra información del disco en formato legible
- `awk 'NR==2 {print $5}'` toma el porcentaje de uso

Así el script también guarda el estado del DAS en el momento del acceso.

## 7. Guardar la información en el log
```bash
printf "%-20s | %-10s | %-15s | DAS: %-5s [LOGIN]\n" \
"$AHORA" "$USUARIO" "$IP_REMOTA" "$ESPACIO" >> $LOG_FILE
```
Esta línea escribe toda la información en el archivo de log.

Los datos que guarda son:
- fecha y hora,
- usuario,
- IP remota o acceso local,
- porcentaje de uso del DAS,
- etiqueta `[LOGIN]` para indicar que fue un acceso.

El operador `>>` añade la información al final del archivo sin borrar lo anterior.

## Qué consigue este script
Este script convierte cada inicio de sesión en un registro histórico.

Eso te permite:
- revisar accesos antiguos,
- detectar patrones,
- llevar control de actividad,
- mejorar la auditoría del sistema.
