# check_sistema.sh

## Qué hace este script
Este script revisa el estado del sistema y muestra información básica del servidor.

Sirve para:
- comprobar si todo funciona correctamente,
- ver el uso de disco,
- revisar memoria y estado general,
- tener un diagnóstico rápido del sistema.

## Por qué se usa
En un servidor es importante saber si:
- el disco está lleno,
- la memoria está saturada,
- o hay problemas generales.

Este script te da esa información en un solo comando.

## Explicación línea por línea

### Flujo completo del script

- Muestra fecha y hora
- Muestra uso de disco
- Muestra uso de memoria
- Muestra uptime del sistema

```bash
#!/bin/bash

echo "===== ESTADO DEL SISTEMA ====="

echo ""
echo "Fecha:"
date

echo ""
echo "Uso de disco:"
df -h

echo ""
echo "Uso de memoria:"
free -h

echo ""
echo "Tiempo activo del sistema:"
uptime
```

## 1. Mostrar título
```bash
echo "===== ESTADO DEL SISTEMA ====="
```
Muestra un encabezado para organizar la salida.

## 2. Fecha actual
```bash
date
```
Muestra la fecha y hora actual del sistema.

## 3. Uso de disco
```bash
df -h
```
- Muestra todos los discos montados
- Indica cuánto espacio está usado y disponible
- El parámetro `-h` lo hace legible (GB, MB)

## 4. Uso de memoria
```bash
free -h
```
- Muestra la memoria RAM usada y disponible
- También en formato legible

## 5. Uptime
```bash
uptime
```
Muestra:
- cuánto tiempo lleva encendido el sistema,
- carga del sistema,
- número de usuarios conectados.

## Qué consigue este script
Permite tener una visión rápida del estado del servidor sin necesidad de ejecutar varios comandos manualmente.
