# Alertas por Telegram — Notificaciones en Tiempo Real

## 📱 Cómo Funciona

1. Script detecta un evento
2. Envía POST a API de Telegram
3. Notificación llega al móvil del administrador
4. Puede responder con acciones (via n8n)

## Eventos Monitoreados

-  SSH login
-  Contenedor caído
-  Base de datos sin respuesta
-  RAM baja
-  Disco lleno
-  Acceso a archivos sensibles
